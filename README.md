# Side-Tetris

## 개요
- 기존 테트리스는 위에서 아래로만 블록이 떨어집니다.
- Side-Tetris는 위→아래, 왼쪽→오른쪽, 오른쪽→왼쪽 3가지 방향에서 블록이 등장하는 변형 테트리스 게임입니다.
- 정사각형 보드를 사용하며, 컨트롤 키로 회전, 스페이스바로 하드 드롭, 방향키로 이동 및 소프트 드롭이 가능합니다.

## 게임 매뉴얼
1. 시작
   - 브라우저에서 `index.html` 파일을 열고, 시작 버튼을 클릭하여 게임을 시작합니다.
   - html파일 여는 법: 터미널을 열고 .\index.html 이라고 치면 인터넷 창에 열리면서 바로 시작.
2. 블록 이동 및 조작
   - 스페이스바: 블록 하드 드롭
   - 컨트롤(Control): 블록 회전
   - 방향키
     - 아래 낙하 시: ←/→ 이동, ↓ 소프트 드롭
     - 왼쪽 낙하 시: ↑/↓ 상하 이동
     - 오른쪽 낙하 시: ↑/↓ 상하 이동
3. 점수
   - 한 줄(가로 또는 세로 라인) 삭제 시 10점 획득
4. 게임 오버
   - 보드 최상단(row 0)에 블록이 쌓이면 게임 오버

## 설치 및 실행 방법
```powershell
# 저장소 복제
git clone https://github.com/hwiery/side-tetris.git
cd side-tetris

# 브라우저에서 실행
start index.html
```
